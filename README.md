# Demo VR Cave 

This project is a study focused on Virtual Reality (VR) mechanics, developed in Unity. Since a physical headset was not used during development, the project is fully optimized for the XR Device Simulator, allowing interaction via keyboard and mouse.
The demo features a cave environment where the player must explore, interact with objects, and reach to a discovery of a majestic Temple Cave hidden deep.

## Key Features
- Initial Setup: User input system to register the player's name before starting.
- HUD: Real-time display of the Player's Name and a Playtime duration.
- Power-up System: "Power Activate" collectible that unlocks the ability to sprint (Shift).
  
## XR Interactions:
- Object grabbing (Torch).
- Laser-based interaction for distant objects (Near Far Interaction).
- Door interaction.
- Cinematics: Final cutscene created using Unity Cinemachine.
- High-Score System: Post-game leaderboard displaying the player's name, total time, and rank.
  
## Controls (XR Device Simulator)

Since this project uses the XR Device Simulator, use the following controls to navigate the VR space without a headset:
- Keyboard and mouse
- Movement:	W A S D
- Sprint: Shift (Only after picking up Power-up)
- Control Hands:	Tab (Toggle between camera and hand control)
- Interact (Laser):	Point Laser + G
- Grab Object:	Use controller grip (G)
- Rotate Camera:	Mouse Movement
  
## Tools
- Engine: Unity 2022.3+
- XR Framework: XR Interaction Toolkit.
- Cinematics: Cinemachine.
- Tools: XR Device Simulator (for non-headset development).

## Gameplay 
- Input Name: Enter your name and click the button PLAY to start the game.
- Exploration: You start in a dark cave. 
- The Torch: Find and grab the torch to light your path.
- Power Activate: Find the "Lightning" box to gain extra speed.
- The Door: Head to the main gate, use your interaction laser, and press G to open.
- Finale: After the cinematic sequence ends you can check your position and time score on the High-Score board.
